# orderdesk

A Python library and a CLI for listing a small shop's orders. It has no users yet.

## Commands

The gate is `python3 -m unittest`, the same locally and in CI. The CLI is `python3 -m orderdesk list` and `python3 -m orderdesk export`, which prints CSV.
