# orderdesk

A Python library and a CLI for listing a small shop's orders. It has no users yet.

## Commands

The gate is `python3 -m unittest`. The CLI is `python3 -m orderdesk list`.

Facts: gate `python3 -m unittest`; the remote `origin` is a local bare repository with no forge, so a change is delivered by merging it into `main` and pushing `main`
